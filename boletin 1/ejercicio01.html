En el grado de DAM veremos algunos lenguajes de programación como:

  • Java
  • HTML
  • SQL
  • Kotlin

Para realizar un commit y push en github tenemos que:

  1. Tener el archivo conectado al repositorio correspondiente
  2. Realizar cambios en el archivo
  3. Usar git add . para añadir todos los cambios
  4. Usar git commit -m "mensaje del commit" para subir los cambios de manera local
  5. Usar git push para subir los cambios a tu repositorio de github

Definición de los términos HTML, CSS y DOM

HTML:
define la estructura y el contenido de una página web.
CSS:
controla su apariencia, como colores, tamaños y distribución.
DOM:
representa la página como una estructura de elementos que JavaScript puede consultar y modificar.
